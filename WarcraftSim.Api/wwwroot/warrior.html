WoW Forever Warrior Simulator

Run a level-60 Warrior against a configurable single target. Select your race, equipment and talents, configure a timed encounter, and compare seeded DPS results. This alpha is not yet a calibrated raid-performance predictor.

Encounter target & timed phases

Single-character sims run for a fixed duration. The target's displayed health percentage is scripted by time and is not reduced by your damage. Raid simulations will use actual boss health.

Set 0 for no execute phase; values longer than the fight cover the whole fight.
Optional. E.g. 90:60 then 150:20 means 60% at 90s, 20% at 150s. Milestones change health % immediately (not gradually) and replace the simple final-execute-phase setting. Leave blank for the final 30 seconds.

Rotation / priority

Rules run top-to-bottom; the first usable, learned ability wins. Talent abilities you haven't selected are retained in a custom list but skipped during simulation. Conditions within a row are ANDed. For example, set Max AP on Execute to prefer Bloodthirst at higher AP. Execute is always restricted to the scripted ≤20% health phase; Rend requires a missing bleed.

Use the arrow buttons to change order. Enable Slam/Cleave above before adding them here. Custom mode does not yet provide a fully optimized rotation.
