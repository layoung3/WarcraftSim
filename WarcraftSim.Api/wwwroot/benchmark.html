WarcraftSim — Configuration Benchmark

Compare two valid simulator setups with the same seeds and fight durations. This page runs inside your local API and requires no PowerShell, additional C# packages, or external services. It does not calculate or install gear stats.

Start with 10 seeds per duration, then increase to 50 when the setups are valid. Every iteration compares A and B with identical seeds; requests run sequentially so the API isn't flooded.

CP135 controls are illustrative, unequipped characters. They compare the old and revised rotation toggles, not pre-raid gear, optimized talents, or verified Forever spell values. These files live under /benchmarks, not your cleared /presets folder.
