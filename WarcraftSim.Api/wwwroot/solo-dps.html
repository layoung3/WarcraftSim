Enhancement manual assumptions
Partial historical-provisional 0/36/0 starting build: 36 allocated, 15 unspent. Not an optimized complete build or current-client certification. Only twelve reconciled talents are currently selectable; broader source-backed catalog integration remains pending.
One level-63 target, initially at 100% Health. Physical damage uses the target armor below; Nature damage is unmitigated. Weapon budgets, hit/crit, imbues and regeneration remain provisional manual assumptions.
Player maximum health is a separate fallback, not target health. Supplied observed or historical-proxy naked Health takes precedence over this manual fallback; the exact preview shows effective Health.
Catalog gear and enchants, external modifiers, racial combat effects, custom priorities, generic scripts, adds and batch statistics are unavailable in this adapter. Disabled modifier tiles do not execute. Supported combat inventory is explicit and starts empty.

      
Shadow health assumptions
Fixed level-63 unmitigated target. These are separate target and player-health inputs, not an encounter script.
Manual Priest maximum health is used only when the selected baseline has no supplied naked Health. Supplied observed or historical-proxy naked Health takes precedence, so this input may not change effective Health. The current preview shows the value used.

Manual weapon and shield assumptions

      
No complete sourced shield is currently selectable. Protection requires tank mode, boss auto-attacks, a shield and a one-handed weapon. These editable simulation assumptions are not a catalog item or verified equipment stats. Manual shield mode uses manual block stats and requires both equipment hand slots to be empty; catalog weapons otherwise take precedence.

      

       
       
       
       
       
       
       
      

      
The manual Protection example explicitly enables tank mode and incoming boss attacks, assumes a one-handed 80-120 weapon at 2.0 seconds and a shield with 5% block chance / 60 block value, and uses Defensive Stance. It does not equip an item or allocate talents. Learn Shield Slam in Talents to use it.

COMBAT PRIORITIES
Rotation
Automatic priorities follow your current talents. A custom ordered list overrides them only when explicitly applied.

      
Fixed Enhancement rotation
Read-only initial priority projected from the actual runtime. The toggles in Encounter and live combat conditions determine execution. This preview is not a predicted cast sequence.

      
Fixed Shadow rotation
Read-only toggle-owned priority. Custom priorities, Discipline and Penance are unavailable.

      

      
Ability priority
Mage and Warlock use the engine’s actual priority model. Customize by reordering one ability per line; an empty list restores talent-aware defaults. The backend rejects unlearned or unsupported abilities.
